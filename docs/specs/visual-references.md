| Room editing        | REF-05           | Labeled form and category choices                  | Canonical categories/targets; archive preserves history and respects active-session conflicts                                                                          |
| Device/module setup | REF-06           | Context, identifiers, alias and save feedback      | Manual creation; ID read-only afterward; one-time token copy/save into firmware; explicit rotation and history-preserving archive                                      |
| Assessment          | REF-07           | Dominant result, target/delta and channel evidence | Live complete fresh three-sensor mean; saved session aggregate/history/PDF preserve target snapshots and expose counts/gaps; no uniformity or spatial-coverage verdict |

Navigation follows sign-in -> rooms -> room/session setup -> live measurement -> saved assessment -> history/PDF report, with supporting module setup and room forms returning to their parent. Actual route filenames belong to implementation. Keep only fully backed navigation destinations; no placeholder Audit/Compliance tab is required by the references. History/PDF has no supplied screen reference: compose it from the settled shared components and real report contract, rather than inventing a new visual style.
